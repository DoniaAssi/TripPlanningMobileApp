## 📱 About the App

**Trip Planning Mobile App** is an Android application designed to help users organize and manage their trip plans.

The application allows users to add, view, search, edit, and manage trip items through a simple and user-friendly interface.

## ✨ Features

- View trip items using **RecyclerView**
- Add new trip items
- Edit existing trip items
- Search for trip items
- Manage trip items
- Select dates using **Date Picker**
- Store data locally using **SharedPreferences**
- Handle RecyclerView item events
- Multiple Activities
- Lifecycle state management
- Interactive UI components:
  - **CheckBox**
  - **RadioButton**
  - **Switch**
- Static images

## 🛠️ Technologies Used

- **Java**
- **Android Studio**
- **XML**
- **RecyclerView**
- **SharedPreferences**
- **DatePicker**
- **Android Activities**
- **Activity Lifecycle**

## 📂 Project Structure

The project is organized into multiple activities and components for managing trip information, with all application data stored locally using **SharedPreferences**.
